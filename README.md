# Rehearsal Book

One document per song. You add:

- **Lyrics**
- **Notes (do re mi)**, kept exactly as you type them
- **Key** (major or minor), with a keyboard that shows the key and plays the key note, chord and scale
- **Recordings** of your rehearsal. Record in the app, then sync the lyrics once. The lines light up while the recording plays, and tapping a line jumps to it.

Everything is saved on the phone and works without data.

## Install on Android

Every push builds the app. Open the **Releases** page of this repo, download `Rehearsal-Book.apk` from **Rehearsal Book for Android**, open it on the phone and allow "install unknown apps" when asked. The first build takes about five minutes after a push.

## Use in a browser

`www/index.html` is the whole app. Open it in Chrome, or host the `www` folder.
